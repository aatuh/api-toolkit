# Options Struct Audit

Audience: maintainers reviewing stable or compatibility-only exported options
structs.

This audit covers exported struct types named `Options` or ending in `Options`
inside root packages classified as `stable` or `compatibility-only` in
`docs/package-classification.tsv`. Each row records defaults, validation
behavior, zero-value behavior, and example evidence. Keep this file in the same
change as any stable options-struct addition or semantics change.

| Package | Type | Defaults | Validation Behavior | Zero-Value Behavior | Example Evidence |
| --- | --- | --- | --- | --- | --- |
| `github.com/aatuh/api-toolkit/v4/authorization` | `PolicyAuthorizerOptions` | `ContextProvider` defaults to nil, so no extra policy context is attached; `DenyOnError` defaults to false, so policy-engine errors are returned. | `NewPolicyAuthorizer` stores the options; a nil engine is rejected when `Can` is called. | Valid when a policy engine is supplied; zero options mean no context enrichment and no deny-on-error conversion. | `authorization/policy_test.go` and `authorization/authorization_additional_test.go`. |
| `github.com/aatuh/api-toolkit/v4/httpx` | `ErrorOptions` | `Mode` defaults to `ErrorModeDefault`; `TypeRegistry` defaults through the built-in Problem Details registry. | Nil registries are normalized; no constructor error is returned. | Valid; maps sentinel, typed, validation, and generic errors with default detail behavior. | `httpx/problem_catalog_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/auth/tenant` | `Options` | `Optional` defaults false; configured source names are trimmed; nil `ErrorHandler` uses the default Problem Details writer. | `New` requires at least one tenant source; `URLParam` requires `URLParamExtractor`; request-time values must be present and agree when required. | Invalid because no tenant source is configured. | `middleware/auth/tenant/example_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/idempotency` | `Options` | With a valid store, empty values default to `Idempotency-Key`, 24 hour replay TTL, 2 minute in-flight TTL, 1 MiB body and response capture limits, default hashing, unsafe-method handling, `Idempotency-Replayed`, system clock, and no-op logger. | `New` requires a store implementing token-aware release; TTLs and byte limits must be non-negative; mixed-version in-flight TTL and clock preflight checks can hard-fail when enabled. | Invalid without a store; with a valid store, remaining zero fields resolve to defaults. | `docs/idempotency.md` and `middleware/idempotency/idempotency_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/json` | `Options` | `RequireJSON` defaults false. | `New` has no option validation; runtime content-type parsing fails closed only when `RequireJSON` is true and the request method/body requires JSON. | Valid no-op middleware. | `contracttest/runtime_compat_test.go` and `middleware/json/json_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/maxbody` | `Options` | No implicit byte limit is provided. | `New` requires `MaxBytes` greater than zero. | Invalid because `MaxBytes` is required. | `middleware/maxbody/example_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/querylimits` | `Options` | Empty limits default to 100 query params, 100 byte keys, 2048 byte values, `limit` as the pagination parameter, maximum limit 100, and the default Problem Details error writer. | `New` rejects negative limits; request-time parsing rejects invalid or excessive pagination limits. | Valid; applies the safe defaults above. | `middleware/querylimits/example_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/ratelimit` | `Options` | Empty values default to capacity 20, refill rate 10 tokens per second, 10 minute state TTL, cleanup interval at half the TTL with a 1 second floor, system clock, and client IP or remote address keying. | `New` rejects negative numeric durations and rates; dangerous bypasses require both `SkipHeader` and trusted proxies. | Valid in-memory limiter defaults. | `docs/cookbook.md` and `middleware/ratelimit/ratelimit_test.go`. |
| `github.com/aatuh/api-toolkit/v4/middleware/secure` | `Options` | Public construction uses functional options; `secure.New()` starts from API CSP, `no-referrer`, `DENY`, `nosniff`, one year HSTS with subdomains, and trusted-proxy-aware scheme resolution. | Functional options mutate the default config; `New` rejects negative HSTS max age. | The exported struct is not the direct construction path; use `secure.New()` for zero-argument defaults. | `github.com/aatuh/api-toolkit/v4/middleware/timeout` | `Options` | `MaxCaptureBytes` defaults to 1 MiB for hard timeouts; `EventHooks` defaults nil. `Timeout` has no default. | `NewPropagator` and `NewHard` require positive `Timeout`; `NewHard` rejects negative `MaxCaptureBytes`. | Invalid because `Timeout` is required. | `middleware/timeout/example_test.go`. |

| `github.com/aatuh/api-toolkit/v4/routepolicy` | `LintOptions` | All booleans default false, and public/admin path lists default empty. | There is no constructor; enabled checks produce `LintFinding` values, and empty path lists mean no path-specific exemptions. | Valid no-op lint configuration. | `routepolicy/routepolicy_test.go`. |
| `github.com/aatuh/api-toolkit/v4/specs` | `RegistryOptions` | Empty or unknown `OpenAPIVersion` normalizes to OpenAPI 3.0.0; `OpenAPIVersion31` opts in to 3.1.0. | `NewRegistryWithOptions` normalizes unsupported versions rather than returning an error. | Valid; emits OpenAPI 3.0.0. | `specs/registry_test.go` and `docs/release-notes.md`. |
| `github.com/aatuh/api-toolkit/v4/specs` | `SchemaOptions` | Empty `RefPrefix` emits inline schemas without component refs. | Schema generation rejects nil types, recursive types, unsupported maps, and invalid examples during generation. | Valid; uses inline schema generation. | `specs/schema_test.go` and `docs/cookbook.md`. |
