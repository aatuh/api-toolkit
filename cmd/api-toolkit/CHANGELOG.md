# CLI changelog

This changelog covers only the independently versioned
`github.com/aatuh/api-toolkit/cmd/api-toolkit/v5` module.

## Unreleased

- The v5 CLI module is extracted from the v4 contrib command. It continues to
  generate applications pinned to explicit v4 core and contrib versions until
  the corresponding v5 modules are published.
- Existing v4 invocation remains available for its documented compatibility
  window; see [the migration guide](../../docs/cli-v5-migration.md).
